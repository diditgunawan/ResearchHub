# ADR-006: No humanizer / AI-detector evasion features
- Status: accepted
## Context
Some tools rewrite text specifically to avoid AI detectors. This undermines transparency expected by journals and institutions.
## Decision
Do not build such features. Offer language-editing assistance that is logged and covered by an AI-use disclosure statement instead.
## Consequences
+ Integrity alignment with publisher/COPE-style norms. − Excludes a feature some users request.
