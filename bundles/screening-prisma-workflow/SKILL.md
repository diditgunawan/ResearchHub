# Screening & PRISMA Workflow Protocol (SCR)

Goal: a rigorous, auditable screening workflow where humans decide and PRISMA numbers are *derived*, never typed.

## Preconditions
Read `AGENTS.md`; load `research-integrity-ai-ethics` if AI suggestions are touched; always `fullstack-engineering-standards` and `qa-security-deployment`. Read `references/requirements.md`, `references/state-machine.md`, `references/prisma-flow-spec.md`.

## Protocol
**P1 — Protocol first.** A review needs a versioned protocol (question, framework PICO/PEO/SPIDER/custom, inclusion/exclusion criteria, databases, date range, blind mode). Screening cannot start without protocol v1. Edits create a new version; decisions record `protocol_version`.
**P2 — Stages.** `title_abstract` → `full_text`. Items advance only via the rules in `state-machine.md`.
**P3 — Decisions are append-only.** Insert rows into `screening_decisions`; a change is a new row with `supersedes_id`. No UPDATE/DELETE grants on that table (ADR-003). Exclusion at either stage requires a reason from the controlled list (global defaults + project additions).
**P4 — Blind mode.** When on, reviewers cannot see others' decisions or AI suggestions until they submit their own for that item/stage. Enforce in the API query, not just the UI.
**P5 — Conflicts.** Verdict mismatch between required reviewers creates a conflict; only a third action (`screening_resolutions`) by owner/designated resolver closes it. Unresolved conflicts block stage advancement.
**P6 — Agreement.** Compute raw agreement and Cohen's kappa per stage from the log (see requirements for formula and edge cases).
**P7 — AI suggestions (optional).** Generated by a job per item with rationale mapped to criteria; stored in `ai_suggestions`; displayed only as *suggestions* (collapsed by default, labelled), never auto-applied, never counted as a reviewer. Log usage via ETH. Record whether the human's decision matched.
**P8 — PRISMA 2020 flow.** Compute from log + import batches (`references/prisma-flow-spec.md`). Provide numbers + SVG/PNG/CSV export. Numbers MUST reconcile or the endpoint returns a reconciliation error listing discrepancies.
**P9 — UX.** Keyboard-first screening (I/M/E, arrows), keyword highlighting from criteria, progress, undo-last (creates superseding row), resumable.
**P10 — Export.** Export the full decision log (CSV) with timestamps, reviewers, reasons, protocol version.

## Hard rules
- MUST NOT mutate or delete decisions.
- MUST NOT show peer decisions to a blind reviewer.
- MUST NOT apply AI suggestions automatically.
- MUST NOT hand-edit PRISMA counts.

## Definition of Done
Relevant `SCR-*` MUSTs pass; two-reviewer scenario tests (including conflicts and protocol version change) green; PRISMA reconciliation tests green; handoff written.
