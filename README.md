# ResearchForge Agent Protocols

Nine skill bundles + complete blueprints for AI agents (Claude Code, Cursor, Copilot, Windsurf, etc.) building a research web application:
**find → map → library → screen (PRISMA) → grounded synthesis → positioning → integrity checks → journal matching.**

## Continuing development (other agents start here)
1. Read `docs/PROJECT_STATE.md`, then `docs/DEVELOPMENT_GUIDE.md`.
2. Use `docs/AGENT_PROMPTS.md` to start a milestone.
3. `MANIFEST.md` lists every file and its purpose.

## Quick start (vibe coders)
1. Create your repo; copy `AGENTS.md`, `blueprints/`, `templates/`, and `scaffold/*` into it.
2. Install bundles as skills:
   - **Claude Code:** copy each folder in `bundles/` to `.claude/skills/` (project) or `~/.claude/skills/` (global).
   - **Claude.ai / Cowork:** zip each bundle folder and upload under Settings → Skills.
   - **Cursor / Windsurf / Copilot:** keep `AGENTS.md` at root; point rules to `bundles/*/SKILL.md`.
3. Start the agent with: *"Follow AGENTS.md. Start Milestone M0 from blueprints/10-roadmap-backlog.md."*
4. After each task the agent updates `docs/PROJECT_STATE.md`. You review the handoff, then say "next".

## Operating principles
- Requirements have IDs and gates; agents cite them in commits and tests.
- Humans decide inclusion/exclusion, authorship, and submission. AI suggests with evidence.
- Built on open data (OpenAlex, Crossref, PubMed, Unpaywall, etc.). No scraping of, or copying from, Rayyan, Consensus, JurnalHub, Open Knowledge Maps, PaperTree, or any third party (open-source code only under its verified licence, ADR-008).
- API limits and licences drift: agents must re-verify at build time (rule G3).

Run `python scripts/validate_bundles.py` after editing any bundle.
